# BGA File Checklist

> Author: A1 — BGA Platform Research Agent. One-page per-file reference.
> All citations are inline `[URL]`. Filenames marked `(legacy)` have a modern `(modern)` replacement; teams should pick one toolchain and stay consistent.

| File | Purpose | Required / Optional | Notes |
|---|---|---|---|
| `gameinfos.inc.php` (legacy) / `gameinfos.jsonc` (modern) | Game metadata: name, designers, players array, BGG ID, undo flag, favorite-color flag | Required | Set `'db_undo_support' => true` to enable undo savepoints [https://en.doc.boardgamearena.com/Main_game_logic:_yourgamename.game.php]. Set `'exception_on_warning' => true` so PHP warnings raise exceptions instead of silently continuing [https://en.doc.boardgamearena.com/BGA_Studio_Migration_Guide]. Modern uses JSON-with-comments [https://en.doc.boardgamearena.com/Studio]. |
| `gameoptions.inc.php` (legacy) / `gameoptions.json` (modern) | Table-creator options (variants, expansions, beginner/no-beginner gates) | Optional | Each option has `name`, `values` map (each with `name`, optional `description`, `tmdisplay`, restriction flags), `default`, `level`. Reserved IDs 200–299 [https://en.doc.boardgamearena.com/Game_options_and_preferences:_gameoptions.inc.php]. |
| `gamepreferences.json` | Player-side cosmetic preferences (layout, auto-prompts) | Optional | Each pref: `name`, `values` (with optional `cssPref` class on `<html>`), `default`, optional `needReload` [https://en.doc.boardgamearena.com/Game_options_and_preferences:_gameoptions.inc.php]. |
| `material.inc.php` (legacy) / inline PHP constants (modern) | Static game data: piece types, costs, ability tables, deck composition | Required (if any static tables) | Comments must not share a line with code in PHP arrays. Avoid runtime mutation [https://en.doc.boardgamearena.com/Studio]. |
| `stats.inc.php` (legacy) / `stats.json` / `stats.jsonc` (modern) | Per-game and per-player statistics declarations | Required for alpha | Each stat needs a unique integer ID; meaningful stats are an alpha gate [https://en.doc.boardgamearena.com/Pre-release_checklist]. |
| `dbmodel.sql` | DB schema | Required | `CREATE TABLE IF NOT EXISTS … ENGINE=InnoDB DEFAULT CHARSET=utf8mb4`; primary keys mandatory; comments on own lines; do not modify `global`/`stats`/`gamelog`/`bga_*`; `player` table is extensible only [https://en.doc.boardgamearena.com/Game_database_model:_dbmodel.sql]. 64MB cap. Schema immutable during gameplay. |
| `<gamename>.game.php` (legacy) / `Game.php` (modern) | Main game class: setup, getAllDatas, action handlers, state callbacks | Required | Stateless — instantiated per request; never read in-memory state across requests [https://en.doc.boardgamearena.com/Main_game_logic:_yourgamename.game.php]. |
| `<gamename>.action.php` (legacy) | Bridge from AJAX to game class; arg parsing only | Required only in legacy framework | Each handler `setAjaxMode()` → delegate → `ajaxResponse()`. Modern framework eliminates this file in favor of `#[PossibleAction]` methods [https://en.doc.boardgamearena.com/Players_actions:_yourgamename.action.php] [https://en.doc.boardgamearena.com/State_classes:_State_directory]. |
| `states.inc.php` (legacy) / `modules/php/States/*.php` (modern) | State machine definition | Required | Four state types: `GAME`, `ACTIVE_PLAYER`, `MULTIPLE_ACTIVE_PLAYER`, `PRIVATE`. IDs 1 and 99 reserved [https://en.doc.boardgamearena.com/Your_game_state_machine:_states.inc.php]. Modern uses class-per-state [https://en.doc.boardgamearena.com/State_classes:_State_directory]. |
| `<gamename>.js` (legacy) / `Game.js` (modern) | Frontend lifecycle, notifications, click handlers | Required | Hooks: `setup`, `onEnteringState`, `onLeavingState`, `onUpdateActionButtons`, `setupNotifications` (or `setupPromiseNotifications`) [https://en.doc.boardgamearena.com/Game_interface_logic:_yourgamename.js]. |
| `<gamename>.css` | All stylesheet rules (single file enforced) | Required | One file only; z-index < 900; sprite-sheet via background-position; prefix custom classes; honor `[data-theme="dark"]` and `spectatorMode` [https://en.doc.boardgamearena.com/Game_interface_stylesheet:_yourgamename.css]. |
| `<gamename>_<gamename>.tpl` | Static HTML skeleton injected on page load | Required (if no `view.php`) | Use template literals or `view.php` for dynamic markup [https://en.doc.boardgamearena.com/Studio]. |
| `view.php` | Server-rendered dynamic template (alternative to `.tpl`) | Optional | Pick one of `.tpl` or `view.php` [https://en.doc.boardgamearena.com/Studio]. |
| `modules/php/` | Extra PHP classes, action handlers, state classes | Optional (legacy) / Required (modern) | Modern state classes live in `modules/php/States/`; helper classes in sibling folders [https://en.doc.boardgamearena.com/State_classes:_State_directory]. |
| `modules/js/` | Extra JS modules (per-state UI controllers, helpers) | Optional | Modern pattern: register state handlers via `this.bga.states.register()` from per-state JS modules [https://en.doc.boardgamearena.com/Create_a_game_in_BGA_Studio:_Complete_Walkthrough]. |
| `modules/css/` | Source SCSS or split CSS to be **compiled into the single `<gamename>.css`** | Optional | The build must still produce a single CSS file [https://en.doc.boardgamearena.com/Game_interface_stylesheet:_yourgamename.css]. |
| `img/` | Game art (sprite sheets, backgrounds, icons) | Required | Each image < 4MB; total assets < 15MB; sprite-sheet anything that can be [https://en.doc.boardgamearena.com/Pre-release_checklist]. |
| `sounds/` | Audio cues | Optional | Pre-release allows freeware/licensed only [https://en.doc.boardgamearena.com/Pre-release_checklist]. |
| `fonts/` | Custom typefaces | Optional | Freeware fonts must have proper licensing on file [https://en.doc.boardgamearena.com/Pre-release_checklist]. |
| `misc/` | Studio-only working files (not deployed) | Optional | Not shipped to production [https://en.doc.boardgamearena.com/Studio]. |
